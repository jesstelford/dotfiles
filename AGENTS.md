# AGENTS.md

Agent notes for this repo. `README.md` is the human-facing documentation and the
place to start.

## Keep the installed-tools list current

The **What gets installed** list in `README.md` must be kept up to date: any
change that adds, removes or replaces a tool — in `.chezmoiscripts/`,
`.chezmoiexternal.toml` or `.chezmoidata.toml` — updates that list, with a link
to the tool's homepage, in the same commit.
